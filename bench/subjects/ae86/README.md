# ae86-k24-swap

Project log and tooling for swapping a Honda K24A2 (2004 Acura TSX donor) into my
1985 Toyota Corolla AE86 (SR5 trim, converting to 5-lug + hydraulic clutch along the way).

## Layout

- `measurements/` — engine bay and donor dimensions, taken with tape/callipers
- `donor/` — donor engine reference specs (published K24A2 figures)
- `parts/` — parts list with order status
- `calc/` — fitment calculator
- `known-issues.md` — problems observed on the donor/test bench

This is a garage project, worked on weekends. The calculator is the only "code" here
and it is honest about being crude.
