# Rebuild binder — torque sequence & fastener specs

Transcribed from the paper binder, 2026-10. Figures cross-checked against the
Honda TSX 2004 service manual and the Hasport fitment guide.

## Main cap / bearing fasteners

| Fastener | Spec | Notes |
|---|---|---|
| Main cap bolts (K24A2) | 49 N·m + 90° | two-stage, torque-to-yield; single use |
| Rod bolts | 20 N·m + 90° | measure stretch where gauge allows |
| Head bolts, stage 1 | 22 N·m | sequence: center-out spiral |
| Head bolts, stage 2 | 61 N·m | same sequence |
| Head bolts, stage 3 | +90° | same sequence, mark positions |
| Flywheel bolts (single-mass swap) | 103 N·m | thread-locker, star pattern |
| Clutch pressure plate | 32 N·m | star pattern, align with alignment tool |
| Bellhousing to block | 64 N·m | |
| Hasport mount kit through-bolts | 55 N·m | OE-8.8 rating hardware only |
| Crank pulley bolt | 130 N·m | impact-assist, chain held with holder tool |

## Sequence notes (binder, verbatim intent)

1. Deck, heads clean, straight-edge check both (max 0.05 mm warp).
2. Bores honed crosshatch 45°, plates torque-plated.
3. Assembly order: mains → rods (each rotated, ring gaps staggered 120°) →
   head stage 1–3 → timing chain → covers → flywheel/clutch.
4. Break-in: 20 min at 2000–2500 rpm, vary load, then oil and filter change.

## Swap-specific torque notes (AE86 side)

- Crossmember notch bolts (M12 flange): 78 N·m, thread locker.
- Hydraulic clutch slave lines: 14 N·m flare nuts, new crush washers.
- Pickle-fork delete: shifter linkage bushings (SHFT-LNK) 25 N·m.
